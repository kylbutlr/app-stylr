Get started with CSS

Install the foundation, import it once, and use the same semantic roles throughout your interface.

The install command uses the v1.2.0 GitHub tag. Publication to the npm registry is a separate release channel. Published releases

  1. 01

    Install App Stylr

    npm install "github:kylbutlr/app-stylr#v1.2.0"

    Requires Node.js 20 or newer for command-line tools.

  2. 02

    Import fonts and tokens

    @import "app-stylr/fonts.css";
@import "app-stylr/css";

    Import both once in your application stylesheet.

  3. 03

    Use semantic roles

    .panel {
  color: var(--ui-text);
  background: var(--ui-surface);
}

    Use roles such as text and surface instead of copying palette values.

Dark by default, light when selected

App Stylr apps start in dark mode. Set data-app-stylr-theme="dark" on the document. Apps may offer an optional light mode toggle that switches the value to light. Both themes use the same semantic token names.

Local tools. Your files stay local.

App Stylr has no account, cloud service, telemetry, or upload feature. Its commands read and write only the local files and folders you choose.

On this page

No form data, cookies, analytics code, or browser storage is used.

In the command-line tools

Selected inputs are processed locally. Nothing is uploaded by App Stylr.

When you install

Your package provider handles the download. App Stylr code sends no install event.
