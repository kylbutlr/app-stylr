# Adopt v1.3.0

Color, type, spacing and existing generated adapter values remain compatible.
The new optional `app-stylr/controls.css` export requires `data-app-stylr-controls`
on the product root. Products retain all form semantics, labels, validation and
layout. Review legacy select rules that override padding; reserve a separate
chevron inset. Test both themes, keyboard focus and phone-sized controls. Native
open-option menus remain platform-owned where enhanced selects are unsupported.

The Reference now includes working control specimens, without saving values,
submitting forms, or adding storage or network behavior.
