# Migrating to v1.4.2

This patch clarifies icon resolution and updates the browser-extension manifest example. Visual tokens and the Graphite artwork are unchanged from v1.4.1.

Keep the SVG master. Review legibility at 16px and 32px independently of 128px and 512px export quality. For Chromium extension management cards, use top-level icon resources at 16, 32, 128 and 512. Retain a 48px resource in action.default_icon when needed for toolbar rendering. The existing icon generator already emits the directly rendered 512px web PNG.

Existing v1.4.1 consumers do not need a token migration. Update the immutable dependency only when adopting this guidance or template. The Reference favicon remains the blank Graphite tile.
