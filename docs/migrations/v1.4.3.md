# Migrating to v1.4.3

This compatible patch simplifies the Reference toolbar to light/dark mode, accent palette and density. Normal remains the neutral surface default. Surface colors, accent palettes, status meanings, icons and generated adapter interfaces are unchanged.

Existing `data-app-stylr-tone` attributes and Swift `SurfaceTone` choices remain supported. JSON and CSS downloads still contain every preset. Reference URLs with explicit `tone=lighter` or `tone=darker` overrides continue to render and preserve their override during navigation. Ordinary Normal-surface links omit the tone parameter.

No consumer configuration migration is required. Update the immutable package dependency to v1.4.3 when adopting the simplified Reference. For earlier versions, also follow the [v1.4.2 migration](v1.4.2.md).
